## 🐍 About

**Snake Slash** is a modern take on the classic Snake game, built from scratch using **C++** and the **raylib** game development library. This project is a personal milestone that combines passion for game development with a deep dive into programming fundamentals.

The game features a **slash mechanic** – cut through obstacles or enemies while avoiding collisions with your own tail. It's fast‑paced, responsive, and showcases clean code architecture.

## ✨ Features

- 🐍 **Classic Snake Mechanics** with a unique **Slash** ability
- 🎮 **Smooth Controls** – arrow keys for movement, spacebar for slash
- 💡 **Efficient Rendering** – uses `deque` data structure for dynamic body segments
- 🎯 **Collision Detection** – precise and responsive
- 🔊 **Sound Effects** – immersive feedback (if implemented)
- 📊 **Score Tracking** – challenge yourself to beat your high score

<br/>

## 🕹️ How to Play

**Controls**
- **Arrow Keys** – move the snake (up, down, left, right)
- **Space** – slash (cuts through obstacles or enemies in front)

**Objective**  
Eat food to grow your snake and increase your score. Use the slash ability to cut through barriers or enemies that appear on the map. Avoid hitting walls or your own tail – the game ends if you do.
